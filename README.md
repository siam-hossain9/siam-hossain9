### Machine Learning Research

| Project | Result | Stack |
|---|---|---|
| **[few-shot-fine-grained-baselines](https://github.com/siam-hossain9/few-shot-fine-grained-baselines)** | Independent research on frozen pretrained backbones for few-shot fine-grained classification.
